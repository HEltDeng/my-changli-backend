# V1.0.7 候选隔离与安装学校关联

本轮仅候选分支，生产服务与已有部署不回滚、不迁移、不启用新采集规则。

## 关联变更

school_bindings.user_id 允许空值：有有效安装凭据、有效同步确认和客户端学校验证来源时，可先关联匿名安装；平台登录后仍从真实会话获取账号归属。后台安装/设备行包括学校学号与账号上下文。相同学号跨安装/账号保留冲突，不合并账号或权限。已有预约学号不当作学校认证资料。

旧 NOT NULL 表在事务中保留原行、主外键、唯一约束，重复执行不重复插入。内存合成迁移测试验证原行完全相同、integrity_check=ok、foreign_key_check=0，匿名关联可插入、重复有效关联被约束拒绝。没有在本轮生产执行此迁移。

保持已有前台事件归属、设备/安装去重、日/7日/30日趋势及管理员快照。自动化继续覆盖并发写入时卡片/明细/分页/导出一致。

## 本轮实际环境

用户最终要求沿用原测试方式，采用本机独立数据库/目录/测试账号，后端 http://127.0.0.1:8792，后台 /admin/。手机/模拟器以 adb reverse tcp:8787 tcp:8792 连接，不回退生产。

可复现空白环境入口：`.venv/Scripts/python.exe run_candidate_local.py --state-dir <独立输出目录> --port 8792`。目录必须为空或具有 CANDIDATE_ONLY 标记，不能位于源码库内。测试凭据随机生成到该目录 local-test-access.json，不打印密码、不提交到 Git。只绑定回环。测试 APK 用独立包名。

候选收集边界 MY_CHANGLI_CANDIDATE_ONLY=1 只接受 com.mychangli.app.candidate / .debug；正式包上报拒绝。生产默认包名规则保持。新后端接受旧协议的兼容测试仍保留。
